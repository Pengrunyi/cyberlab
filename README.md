# CyberLab V3 — 游戏式设备交互 / Y2K Research Systems

## 双面全景窗：统一城市空间

两面窗户现在直接观察同一世界坐标系：东窗朝 +X，南窗朝 +Z，上下两层使用同一套室外建筑。已移除旋转复制城市的做法。东侧为霓虹商业峡谷和唯一的环冠标志塔，南侧为交通枢纽、能源设施和南向街区。转身、走动或上楼时，建筑保持固定位置，通过相机产生正常透视、视差和遮挡。

建筑生成使用占地间隔与铁路净空约束；高架轨道以连续曲线从东侧转入南侧车站，每节车厢分别采样弧长和切线，不再各窗重复播放列车。地面道路共用标高及交叉口，轨道配有落地支柱。

本轮文件：`src/scene/city.ts`、`worldLayout.ts`、`traffic.ts`、`src/main.ts`、`scripts/inspect-world.cjs`、`README.md`。`node scripts/inspect-world.cjs` 在开发服务器运行时验证唯一地标、建筑占地、轨道净空与转弯车厢，并输出东窗、南窗、二楼南窗截图到 `artifacts/world-*.png`。当前生成 853 栋建筑，占地重叠及侵入轨道走廊的数量均为 0。

范围说明：这里实现统一的三维空间与铁路运动约束，玻璃和雨雾仍使用实时着色近似；城市不是完整的刚体物理模拟，也不可从室内走入。

验收：`npm run build`、`npm run test:collision`、`node scripts/inspect-world.cjs`、`node scripts/inspect-duplex.cjs` 均已通过。浏览器测试覆盖东/南/二楼南窗、实际步入电梯、上下楼、呼梯以及途中暂停后的恢复；无页面错误。构建保留 Vite 的单包体积提示。

Three.js + TypeScript + Vite。原创程序化实验室及 3D 巨型都市，无城市背景图、模型下载、登录、付费 API 或运行时外部服务。

## 二楼生活设备交互

靠近设备，在三米内用准星瞄准并按 E；面板沿用现有设备风格，ESC 关闭，点击继续探索恢复鼠标控制。

- 床：躺下进入枕边视角，累计休息时间；起身、ESC 或关闭面板恢复原来的床边位置和朝向，休息时锁定行走。
- 水龙头：开关水阀，显示出水、水面波纹与用水量；关闭面板保留阀门状态，关闭水阀后停止计量。
- 跑步机：启停、1–12 km/h 速度滑块，带动跑带动画、机身屏幕与累计里程；关闭面板继续运行，再次操作可停止。当前是设备控制，未加入玩家站上跑带的运动模式。

修改：`src/objects/living.ts`、`src/main.ts`、`src/interaction/system.ts`、`src/ui/devicePanels.ts`、`src/ui/devices.css`；新增 `src/ui/livingPanels.ts`、`scripts/inspect-living.cjs`。本轮已通过构建、两层碰撞测试和生活设备浏览器测试（真实 E 键、休息与起身、ESC 恢复、供水开关、速度同步、停止计量及关闭后保留设备状态）；浏览器无页面错误。截图在 `artifacts/living-*.png`。用水量和里程为本地模拟，本轮不持久化到刷新之后。

## 启动

```sh
npm install
npm run dev
```

浏览器打开终端地址，默认 http://127.0.0.1:5173/ 。需要支持 WebGL 2 的桌面 Chrome；Node.js 20.19+ 或 22.12+。`npm run build` 构建，`npm run preview` 预览生产版本。

## 操作

| 输入 | 功能 |
| --- | --- |
| Click to Enter / 点击画布 | 真正锁定鼠标并进入第一人称 |
| WASD | 前后左右移动 |
| 鼠标 | 上下左右环视 |
| Shift | 快走 |
| E | 靠近并瞄准设备，按提示打开操作面板 |
| ESC | 关闭设备面板、环境设置，或释放鼠标 |
| Tab | 行走时先解锁，再打开环境设置 |
| 设置内快速前往 | 解锁状态快速前往安全站点 |
| 重置 | 回到室内安全出生点 |

默认出生在实验室观景窗内侧，视线高度 1.68 米。进入后向前走到玻璃前，按 S 后退即可返回室内；Tab 设置内的“实验室”可以快速回到房间中央。设置支持亮度、主灯、青/蓝/紫氛围色、Bloom、室外雨丝以及精细/流畅画质。设置中 Tab 保留标准表单焦点导航；关闭设备后点击“继续探索”恢复鼠标锁定。

## V3 新增交互

所有设备使用中央准星选取，约 3 米内显示 E 提示和轮廓，家具与墙体会遮挡交互。打开设备立即释放鼠标、清空移动输入；ESC 或右上角关闭按钮退出，点击继续探索后重新锁定鼠标。

| 设备 | 操作 |
| --- | --- |
| 电脑工作台 | 网络扫描、设备诊断、同步显示器、清空日志；终端为本地模拟 |
| 机械臂 | 底座、肩、肘、夹爪滑块；自动抓取、抬升、搬运、释放、回位；随时复位 |
| 全息核心 | 独立 3D 展示、拖动旋转、滚轮缩放、地球/网络模式、节点选择与重置 |
| 实验室后墙屏幕 | 主灯开关、亮度、青/蓝/紫氛围、逐项环境诊断 |
| 落地窗 | 晴夜、小雨、暴雨、浓雾，三秒平滑调整雨量、雾和天空/建筑色调 |

面板使用银蓝标题栏、深色终端和青色状态灯的 Y2K 风格。程序生成交互音与环境雨声，可在任意设备面板底部关闭；无需下载音频。

新增模块：`src/interaction/system.ts`、`src/interaction/terminal.ts`、`src/ui/devicePanels.ts`、`src/ui/devices.css`、`src/ui/hologramViewer.ts`、`src/scene/weatherPresets.ts`、`src/effects/audio.ts`。设备模型与状态分别由 `robot.ts`、`hologram.ts`、`workstation.ts`、`equipment.ts` 管理，`main.ts` 统一更新动画。

## V2 已完成

- 用 PointerLockControls 替换 OrbitControls，实现真实第一人称、平滑移动、方向归一化与水平运动。
- 玩家圆形占地与八组家具 AABB 碰撞，移动子步防止高速穿透；墙壁、落地窗和房间边界限位，碰撞后可沿边滑动。
- 保留电脑桌、机械臂、全息球、实验桌及灯光面板；新增沙发和茶几，补齐房间背墙和顶面。
- 590 栋城市建筑 / 1375 个楼体分段，沿观景方向延伸约 900 米。近景巨楼框住城市峡谷，中景错落，远景使用简化轮廓和大气衰减。
- 多层楼冠、尖塔、偏心体块、悬挑、竖向构架、楼顶设备、立面涡轮、服务连廊、低处道路与高架轨道。
- 立面 Shader 计算窗灯、幕帘、墙面板缝及颜色差异，窗灯不创建独立光源；建筑构件采用 InstancedMesh。
- 8 面程序化动态广告（8 Hz 更新）、四节高架列车、8 辆分层航线飞行器。
- 深蓝紫天空、距离雾、三层柔和动态雨雾、6500 条 GPU 雨丝、玻璃雨珠和水痕。雨只在室外生成。
- ACES 色调映射、显式 sRGB 输出、适度 Bloom；保留少量室内灯光，静态阴影缓存。
- 流畅画质降低像素比、关闭 Bloom、将雨量减至 2200；标签页隐藏时暂停渲染；减少动态效果偏好会冻结环境动画。

## 当前限制与后续完善

这是可探索的实时程序化场景，距离电影资产级画面仍有材质、构图和美术细节的打磨空间。雨雾采用透明层近似体积感；玻璃具有透明度及水痕，但未实现屏幕空间反射或真实折射。建筑边缘仍主要为硬表面，远景按生成距离简化，尚未使用运行时动态 LOD。

碰撞采用二维玩家体与保守家具包围盒，不能跳上桌面，没有楼梯和垂直物理；修改家具布局时需同步更新 `collision.ts`，并重跑可达性测试。快速前往站点属于有意的 UI 传送功能。

V3 已加入终端、机械臂抓取、E 交互与音效。设备数据和诊断均为本地模拟；没有真实硬件或真实网络接入。天气目前保持夜间，无日夜循环或闪电。机械臂采用预设轨迹与简化逆运动学，没有刚体碰撞或任意物体抓取。移动设备可以查看画面和设置，未实现触屏移动。实际帧率取决于 GPU、分辨率和系统负载。


## 2026-11-17：探索与研究交互（选项 1 / 2 / 4 / 5）

- **拿取检视**：一楼左侧实验台上新增离子电池、逻辑芯片、光学传感器。瞄准按 E，在独立 3D 窗口拖动旋转、滚轮缩放，拿入零件包或放回原位。按 I 或左下角按钮打开零件包；未收集的物品必须先到台边拿取。

- **全息城市沙盘**：靠近全息核心按 E，点击“打开全息城市沙盘”。沙盘按实际城市楼体边界生成，853 栋建筑使用单个 InstancedMesh 简化显示；支持拖动、缩放、点选/下拉选择建筑，查看楼高、坐标、距离。橙色轨道与列车、紫色飞行器读取实际世界数据，可追踪或停止追踪。
- **窗边望远镜**：靠近东侧窗按 E，在天气面板点击“使用窗边望远镜”。临时使用贴近玻璃的观察位置，拖动环视或使用角度滑块，滚轮/滑块变焦，锁定列车与飞行器。目标不在朝外的观察范围时会等待，不会将镜头转向室内。ESC 或右上角关闭，精确恢复原位置、朝向及 FOV。

新增文件：`src/objects/research.ts`、`src/ui/researchPanels.ts`、`src/ui/researchViewer.ts`、`src/ui/research.css`。修改 `src/main.ts`、`src/interaction/system.ts`、`src/player/camera.ts`、`src/ui/devicePanels.ts` 以接入现有系统，保留二楼生活区及电梯。
